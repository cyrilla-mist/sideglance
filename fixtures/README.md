# Sideglance Fixtures

This directory contains small deterministic example inputs retained from earlier demo and evaluation work.

Current files live under `demo/`:

- `fearless-behavior.json`
- `friday-context.json`
- `touch-grass.json`

They are **fixtures, not product content**. The current product does not use this directory as its canonical context knowledge base, and these examples should not be mistaken for the scope of Sideglance.

No direct default-branch code reference to `fixtures/demo/` was found during the September 2026 repository cleanup. Keep the files for reproducibility / historical demo context unless a later cleanup confirms they are no longer useful.

Before deleting or repurposing them, check evaluation scripts, demo workflows, and any external documentation that may still expect these fixture names.
